01为什么做这个Why

会话失忆Session amnesia

每次新会话都要重新交代背景、偏好、上次做到哪。Every new session starts from zero: context, preferences, where we left off.

口头承诺不可靠Verbal promises don't stick

"下次我会注意"没有载体。规则必须写进文件并 commit。"I'll remember next time" has no storage. A rule only exists once it's in a committed file.

产出质量不稳定Uneven output quality

报告断链、漏翻译、占位符残留——需要机械检查 + 语义把关。Broken links, missing translations, leftover placeholders — needs mechanical checks plus semantic review.

02架构Architecture

四层：配置 → 规则 → 脚本 → Agent。规则是唯一真相，脚本只负责确定性的数据收集，Agent 负责判断。Four layers: config → rules → scripts → agents. Rules are the source of truth, scripts do deterministic collection, agents do judgment.

03启动流程Startup flow

会话一开始，hook 先跑完所有确定性检查，只把一段摘要注入上下文；Agent 按固定优先级逐项处理，一次只问一个问题。On session start a hook runs every deterministic check and injects only a short digest; the agent acts on it in a fixed priority order, one question at a time.

质量门：脚本给读数（链接、双语、结构、体积），Agent 给结论 PUBLISH-OK / BLOCK / NEEDS-HUMAN。只诊断不修改。Quality gate: the script gives readings (links, bilingual, structure, size), the agent gives the verdict PUBLISH-OK / BLOCK / NEEDS-HUMAN. Diagnoses only.

体检（运行状态）+ 校验（结构契约），给出修复建议。Checkup (runtime health) + validate (structural contracts), with fix suggestions.

kiro-doctor · validate-kiro

子 Agent 以独立进程启动（run-agent.sh），带深度保护防止递归，失败时回退到底层脚本并明确告知。Sub-agents run as separate processes (run-agent.sh) with a depth guard against recursion; on failure the caller falls back to the underlying script and says so.

05纪律框架Discipline framework

同类错误出现两次就提炼成 pattern；pattern 毕业后进入三层纪律。每条规则都要挂来源和一次真实的翻车记录，没有实例的规则不收录。A mistake seen twice becomes a pattern; graduated patterns join a three-tier discipline. Every rule must cite its source and a real failure — no example, no rule.

06可移植 & 去敏感Portable & leak-safe

路径单一来源One path registry

脚本不写死路径，全部从 config/paths.env（相对路径）解析；机器相关值只放在被忽略的 local.env。No hard-coded paths: everything resolves from config/paths.env (relative); machine values live only in an ignored local.env.

泄露防护Leak guard

pre-commit / pre-push 扫描绝对路径、邮箱、密钥；私有敏感词表放在仓库外，敏感词本身永不发布。pre-commit / pre-push scan for absolute paths, emails and keys; a private denylist lives outside the repo so the words themselves are never published.
